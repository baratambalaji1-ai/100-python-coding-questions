# Day 03 - Find Sum of N Natural Numbers

## Problem Statement

Given a positive integer `N`, find the sum of the first `N` natural numbers.

### Example

**Input**
```
5
```

**Output**
```
15
```

### Explanation

The first 5 natural numbers are:

1 + 2 + 3 + 4 + 5 = 15

### Constraints

- `1 <= N <= 10^6`
